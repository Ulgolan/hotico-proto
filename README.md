# hotico-proto

An interactive prototype of the HOTICO site, built to carry a vision from
head to screen. It is a specification, not a product: the screens are real
enough to click through and judge, and that is exactly as far as they go.
ACP (Alex Popescu) owns design authority over every pixel and every word in
it — the Figma file is visual truth, `docs/` is law, and his word overrides
both.

**FATE CLAUSE:** This prototype is a specification. Fork the intent (tokens,
State Map, assets), not the files. This URL retires when the production site
ships.
