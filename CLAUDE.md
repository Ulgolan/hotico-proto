# HOTICO PROTO — Constitution

## What this repo is
A **specification artifact**: an interactive prototype built to transfer a
vision. It exists so a client, a developer, or a future builder can *see*
the intent instead of reading about it.

It is **not** a production seed. Nothing here is engineered to be extended,
scaled, or handed to a production team as a codebase. Fork the intent, not
the files.

## Sources of truth
- `docs/` is law. STATE-MAP, POLARIS, and DOSSIER are written by the Tower.
  This session does not author them.
- `css/tokens.css` is the **only** source of color and type. No hex value,
  no font-family, no shadow is written anywhere else. If a value is needed
  and not in tokens, stop and ask — do not invent it.
- The Figma file is visual truth.
- **ACP's word overrides all of the above.**

## The lap
Every unit of work is a lap, and every lap runs the same course:

1. **branch** — never build on main
2. **build** — execute the brief, nothing beyond it
3. **preview** — serve it locally
4. **ACP's eye** — he looks at it; no session certifies its own work
5. **merge** — only after his word

Stop at every STOP in a brief. Report; do not improvise.

## Standing laws
- `<meta name="robots" content="noindex,nofollow">` in the `<head>` of every
  page, every lap. Permanent.
- `body{max-width:480px}` is law — the desktop grace floor.
- File removals go to **Trash**, never hard-delete. This applies to assets,
  docs, and code alike.
- `LEDGER.md` is read on open and appended on close.
